# Lições

- Nome de usuário da Wikimedia é pessoal: nome de marca ("inematds", "INEMA") é recusado na Wikipédia. Conferir antes de criar a conta. (25/11/2026)
- Fonte colada de outra IA só entra depois de abrir a página e achar a citação; duas não batiam. (25/11/2026)
- Conteúdo marcado como "publicitário" no jornal serve só para fato simples, nunca para provar relevância. (25/11/2026)
- Página que carrega por JavaScript (ex.: Assespro) parece vazia lida sem navegador; abrir no navegador antes de dizer que não existe. (25/11/2026)
